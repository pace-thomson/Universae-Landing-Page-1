# Universae Landing Page

## Deployment

1. Clone this repo to your local machine

2. After cloning, run: 
```bash
npm install
```

3. Then, run this command for compiling to get deployable version

```bash
npm run build
```

At this point, everything you need to deploy will be in the [`/dist`](./dist/) folder. This project is built with [Vite](https://vite.dev/), so serving the site might need to keep that in mind.


## Forms:

> Form submissions are sent to: iss@utahtech.edu

### The following information is asked on the form: 

- name (first and last)
- email
- phone number
- country



## Background
This landing page was created for the purpose of being a landing page for an email campaign for reaching out to Universae students to get them to come to Utah Tech. It initally started focused around the masters programs, but was shifted to be for undergrad, so if you notice some weird changes in the commit history, that's why.
